bare server

This is a placeholder document root, used for local testing and benchmarking. Point a site's root at your own content to serve something real.

This page is deliberately longer than 64 bytes, so the server builds gzip and brotli variants for it at boot. That makes it enough on its own to exercise compression negotiation, ETag/304 revalidation and Cache-Control.

  • Generate a local certificate: ./gen-cert.sh
  • Serve it: use the local test block at the end of server.conf.example
  • Check headers: curl -skI https://localhost:8443/
  • Check compression: curl -sk -H 'Accept-Encoding: br' -o /dev/null -D- https://localhost:8443/
